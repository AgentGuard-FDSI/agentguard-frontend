# agentguard-frontend

La interfaz web del proyecto AgentGuard. Consume la API de
[`agentguard-andimarket`](https://github.com/AgentGuard-FDSI/agentguard-andimarket) para comparar,
lado a lado, el agente sin AgentGuard (Config. A) y con AgentGuard (Config. B).

## Qué va en este repositorio

- **Núcleo:** chat y comparación A frente a B.
- **Ampliación:** inicio de sesión, dashboard y bandeja de aprobaciones.

Tecnología prevista: React, TypeScript, Vite y Tailwind.

## Estado

Repositorio inicializado. Se construye a partir del Avance 3, cuando la API del agente esté disponible.
